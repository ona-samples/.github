# Ona Samples

Sample applications for [Ona](https://ona.com) — ready to explore, copy, and adapt.

**Apps**
- [private-market-hub](https://github.com/ona-samples/private-market-hub) — App for trading in private markets
- [spring-petclinic](https://github.com/ona-samples/spring-petclinic) — Spring Boot Java web application


**Dev Container & Configuration**
- [devcontainer-feature](https://github.com/ona-samples/devcontainer-feature) — Create custom dev container features
- [vscode_extension_from_baseimage](https://github.com/ona-samples/vscode_extension_from_baseimage) — Pre-install VS Code extensions in base images

**Ona Automations**
- [AI Security Engineer](https://github.com/gitpod-io/ai-security-engineer/) - Scan and fix CVEs


**Multi-Repository Setups**
- [multi-repo](https://github.com/ona-samples/multi-repo) — Work with multiple repositories in one environment
- [multirepo-template](https://github.com/ona-samples/multirepo-template) — Template for multi-repo dev environments
- [multirepo-via-uservar](https://github.com/ona-samples/multirepo-via-uservar) — Multi-repo setup using user variables


**Platform & Infrastructure**
- [docker-outside-docker](https://github.com/ona-samples/docker-outside-docker) — Access host Docker daemon from dev containers
- [gpu-demo](https://github.com/ona-samples/gpu-demo) — GPU-enabled development environment
- [ona-android-dev](https://github.com/ona-samples/ona-android-dev) — Android development environment


**Migration**
- [shift-eks](https://github.com/ona-samples/shift-eks) — Use Ona Agent to migrate from OpenShift to EKS


**Tools & Utilities**
- [gitpod.zellij](https://github.com/ona-samples/gitpod.zellij) — Zellij terminal multiplexer plugin for Gitpod
- [wait-for-port-and-open-browser](https://github.com/ona-samples/wait-for-port-and-open-browser) — Auto-open browser when a port becomes available
- [workshop](https://github.com/ona-samples/workshop) — Workshop and training materials
